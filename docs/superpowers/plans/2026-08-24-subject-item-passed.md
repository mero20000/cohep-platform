# Subject Item Passed Toggle Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow servants / level-leaders / admins to mark a specific `SubjectItem` as Passed for a specific `Student`, toggleable (reversible), scoped to allocated items for the student's level/group, with history retained and visible in the student portal.

**Architecture:** New `StudentSubjectPass` table (studentId + subjectItemId, with `revokedAt` for history) + `POST /students/:id/subject-items/:itemId/pass` (toggle) + `GET /students/:id/subject-items` (allocated items with pass state) + frontend toggle in Student Detail (dashboard) + read-only passed history in Student Portal. RBAC via existing `STAFF_ROLES` filtered to `servant, group_leader, level_leader, admin, super_admin` (exclude `curriculum_manager`, `assistant_servant` unless explicitly allowed). Validation checks student and item belong to same school and item is allocated to student's level (via `SubjectItemLevel.levelNumber`).

**Tech Stack:** NestJS + Prisma + PostgreSQL, Next.js (React), class-validator, Jest, `http` client.

## Global Constraints

- No secrets in repo; use `DATABASE_URL` from Render for migrations.
- Follow existing Prisma soft-delete pattern (`deletedAt`) where applicable; `StudentSubjectPass` uses `revokedAt`/`revokedBy` instead of hard delete to keep history.
- RBAC must not use flat `STAFF_ROLES` blindly — filter to `['servant','group_leader','level_leader','admin','super_admin']`.
- Frontend must use `useLanguage`, `useToast`, `getSchoolId`, `assetUrl` where needed; handle `lang === 'ar'` RTL.
- Keep history: toggling off must set `revokedAt` not delete; toggling on after revocation creates a new row.

- Produces: `StudentSubjectPass` model with fields:
  ```prisma
  model StudentSubjectPass {
    id            String   @id @default(uuid())
    studentId     String   @map("student_id")
    subjectItemId String   @map("subject_item_id")
    status        String   @default("passed") // passed
    passedAt      DateTime @default(now()) @map("passed_at")
    passedBy      String   @map("passed_by")
    note          String?
    revokedAt     DateTime? @map("revoked_at")
    revokedBy     String?   @map("revoked_by")
    createdAt     DateTime @default(now()) @map("created_at")
    updatedAt     DateTime @updatedAt @map("updated_at")
    student     Student     @relation(fields: [studentId], references: [id])
    subjectItem SubjectItem @relation(fields: [subjectItemId], references: [id])
    passer      User        @relation("PassedBy", fields: [passedBy], references: [id])
    @@unique([studentId, subjectItemId, revokedAt]) // allow history: only one active (revokedAt null) per pair
    @@index([studentId])
    @@index([subjectItemId])
    @@map("student_subject_passes")
  }
  ```
  Also add relations:
  - `Student.studentSubjectPasses StudentSubjectPass[]`
  - `SubjectItem.studentPasses StudentSubjectPass[]`

- [ ] **Step 4: Implement service methods**

  - `getStudentSubjectItems`: 
    1) Load `Student` with `level.number` and `groupId`.
    2) Find `SubjectItem`s where `SubjectItemLevel.levelNumber === student.level.number` AND item's subject is active (via `Subject.deletedAt null`). This is the "allocated" set per spec (subject-items for student's group and level — group filtering via `Level` not `Group` directly; if Group-specific allocation needed later, extend via `CurriculumAllocation`).
    3) For each item, find active pass `where studentId, subjectItemId, revokedAt null` → `status: 'passed'` else `not_started`.
    4) Also fetch history per item (`where revokedAt not null`) for `history` field.
  - `toggleSubjectItemPass`:
    1) Validate `student` exists, `subjectItem` exists, same `schoolId`, item allocated to student's level (if not allocated, throw `BadRequestException('Subject item not allocated to student level')`).
    2) RBAC: `user.roles` must include one of `['servant','group_leader','level_leader','admin','super_admin']` — if not, throw `ForbiddenException`.
    3) Check active pass exists: `findFirst where studentId, subjectItemId, revokedAt null`.
    4) If exists → revoke: `update where id, set revokedAt: now(), revokedBy: user.id` → return `{ passed: false }`.
    5) Else → create new `StudentSubjectPass` with `passedBy: user.id`, `note: dto.note` → return `{ passed: true }`.
  - `getStudentPassHistory`: `findMany where studentId, revokedAt not null OR revokedAt null` ordered by `passedAt desc` (keep all for portal reference).

- [ ] **Step 5: Add controller routes**

  ```ts
  @Roles('servant','group_leader','level_leader','admin','super_admin')

  async togglePass(@Param('id') id: string, @Param('itemId') itemId: string, @Body() dto: ToggleSubjectItemPassDto, @Req() req: any) {
    return this.studentsService.toggleSubjectItemPass(id, itemId, req.user, dto);
  }

  @Roles('servant','group_leader','level_leader','admin','super_admin','parent') // parent read-only for portal? Or separate portal guard
  @Get(':id/subject-items')
  async getSubjectItems(@Param('id') id: string, @Req() req: any) {
    return this.studentsService.getStudentSubjectItems(id, req.user);
  }

  @Get(':id/subject-items/history') // public for student portal via portalAccessKey? Check StudentPortalAuthGuard alternative
  async getHistory(@Param('id') id: string, @Req() req: any) {
    return this.studentsService.getStudentPassHistory(id, req.user);
  }
  ```

  ```tsx
  export function StudentSubjectItemsPanel({ student, lang }) {
    const [items, setItems] = useState([])
    useEffect(() => { http.get(`/students/${student.id}/subject-items`).then(setItems) }, [student.id])
    const toggle = async (itemId: string) => {
      const res = await http.post(`/students/${student.id}/subject-items/${itemId}/pass`, {})
      setItems(prev => prev.map(i => i.subjectItem.id === itemId ? { ...i, status: res.passed ? 'passed' : 'not_started' } : i))
    }
    return <div className="space-y-2">
      {items.map(({ subjectItem, status }) => (
        <div key={subjectItem.id} className="flex items-center justify-between p-3 rounded-xl border">
          <span>{subjectItem.name}</span>
          <button onClick={() => toggle(subjectItem.id)} className={status==='passed' ? 'bg-green-100' : 'bg-gray-100'}>
            {status==='passed' ? 'Passed ✓' : 'Mark Passed'}
          </button>
        </div>
      ))}
    </div>
  }
  ```
